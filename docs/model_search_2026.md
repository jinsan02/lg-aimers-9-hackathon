# 자연어 인코더/디코더 계열 모델 탐색 (2026-08-05)

전제: 제출 zip 용량은 문제 없음(현재 2.2MB / 10GB). 제약은 **추론 10분(L4)** 과
**라이선스**, 그리고 **이 데이터에 실제로 먹히는가**.

## 🔴 왜 자연어 계열이 이 데이터에서 막히는가

[llm_serialization_handoff.md](llm_serialization_handoff.md) §3의 1차 증거가 결정적입니다 —
팀이 0.5B를 70만 행으로 파인튜닝하고도 `budget < 5000` **임계 하나를 학습하지 못해**
결정론적 규칙 12종으로 우회해야 했습니다. BPE가 `5000`을 `50`+`00`으로 쪼개면 수의 크기
관계가 파괴되기 때문입니다.

그리고 우리 피처는 `balls_before`·`strikes_before`·`inning`·`score_diff`·`li`·
`win_expectancy` — **전부 수치 임계와 대소 비교**입니다. 즉 자연어 토크나이저가 가장 못하는
것만 모아둔 셋이고, 이건 GBDT의 분기 조건 그 자체입니다.

xVal·FoNE 같은 단일토큰 수치 임베딩 연구가 정확히 이 문제를 풀지만, **공개 사전학습
가중치가 없어** 우리가 처음부터 학습해야 하고 — 그러면 "사전학습 지식을 빌린다"는 유일한
동기가 사라집니다. 그 지점에서 TabM/FT-Transformer가 더 낫습니다.

## ❌ TabICLv2 — 실측 결과 기각 (2026-08-05 A100)

아래 검토는 유지하되, **실제로 돌려본 결과 성능에서 탈락**했습니다.

| 컨텍스트 | 24.6만행 환산 (A100/L4) | 부분 BSS |
|---|---|---|
| 10,000 | 0.6분 / 2.3분 ✅ | 33.3 |
| 30,000 | 1.1분 / 4.0분 ✅ | 214.8 |
| 60,000 | 2.6분 / 9.0분 ⚠️ | **229.1** |

**시간은 통과했으나 성능이 CatBoost(783)의 1/3**입니다. 컨텍스트를 6만까지 키워도
122만 학습행의 5%만 보는 셈이라, 전량 학습하는 GBDT를 따라올 수 없습니다.
컨텍스트를 더 키우면 시간이 한도를 넘습니다 — **구조적으로 막힌 조합**입니다.

> 교훈: 벤치마크 우위(TabArena 80%)는 **중소 규모 데이터셋** 기준이었습니다.
> 147만 행 규모에서는 ICL의 컨텍스트 제약이 곧 정보 손실이 됩니다.

## (원 검토) TabICLv2

자연어 모델은 아니지만 "사전학습된 트랜스포머를 가져와 쓴다"는 사용자의 원 목적에 부합하고,
수치를 텍스트로 만들지 않아 위 실패 유형을 회피합니다.

- **성능 근거**: TabArena 데이터셋의 약 80%에서 튜닝된 CatBoost/XGBoost/LightGBM을 상회.
  1만 샘플 초과 데이터셋 53개에서 TabPFNv2·CatBoost보다 우수. TALENT 벤치 평균 순위 2.12 (튜닝 CatBoost 4.07)
- **규모**: 최대 50만 샘플(CPU/디스크 오프로딩), 피처 2,000개까지
- **라이선스**: 코드·가중치 공개, permissive (soda-inria) — 확인 필요하나 Apache 계열
- **속도**: 100피처 기준 H100 5만 샘플에서 TabPFN-2.5 대비 10.6× 빠름

### 우리 조건에서의 미검증 리스크 (실험 전 반드시 확인)

1. **학습 147만 행 > 컨텍스트 50만** → 서브샘플 필요. 시즌 가중 서브샘플(최근 시즌 우선)로 설계
2. **L4에서 24.6만 행 추론 시간** — 가장 큰 불확실성. ICL은 학습셋을 컨텍스트로 들고 가므로
   추론 비용이 GBDT와 차원이 다름. **A100에서 먼저 실측 후 L4 환산**
3. 가중치를 zip 동봉해야 함(인터넷 차단). 크기 확인 필요
4. 시즌 drift 대응이 되는지 — 우리 데이터의 핵심 축인데 ICL이 이걸 잡을지 미지

### 실행 순서 (A100)

1. 가중치·라이선스 확인 → 다운로드
2. **추론 시간 먼저 실측** (24.6만 행). 10분 초과면 즉시 중단 — 성능 볼 필요 없음
3. 통과 시 2024 홀드아웃 BSS 측정, 서브샘플 크기별 스윕
4. 채택 기준: 단독 BSS가 아니라 **현 블렌드(804.70)에 +10 이상 기여**할 때만
