# 구종 보조학습 제구 모델 — 2026-08-11

## 결론

현재 투구의 실제 구종을 추론 입력으로 쓰는 것은 불가능하고 규칙에도 맞지 않는다. 대신
과거 학습행에서만 복원한 구종 3분류를 **masked auxiliary label**로 사용해 공유 trunk를
학습하고, 평가 시에는 주 제구 head만 출력하는 방식은 행 독립·외부 데이터 규칙을 지킨다.

이 방식은 제구 단독 MLP보다 세 rolling transition에서 모두 개선됐다. 반면 예측 구종을
직접 주변화한 `P(success|x)=ΣP(type|x)P(success|x,type)` MoE는 보조 head 방식보다 약해
확장하지 않았다. 즉 채택된 기전은 “구종을 맞혀 제출한다”가 아니라 “구종 구조가 제구용
표현을 정규화한다”이다.

## 데이터 경계

- main↔Trackman의 strict 1:1 매칭 행에서만 fastball/breaking/offspeed 라벨을 만든다.
- 전체 학습행 라벨 coverage는 75.17%다. 미매칭 24.83%는 구종 CE에서만 제외한다.
- 구종 라벨은 학습 전용이다. 제출 ZIP에는 Trackman 원자료·join table·구종 라벨이 없다.
- 추론 입력은 대회 `test.csv`의 현재 행 피처와 2019–2024에서 동결한 artifact뿐이다.
- 다른 평가행, row_id 순서, 직전 평가행, 평가 배치 통계를 사용하지 않는다.

## 모델

- 입력: 현행 121개 피처(수치 112, 범주 9), raw pitcher/batter ID 제외.
- trunk: `768 → 384 → 192`, BatchNorm + SiLU + dropout 0.15.
- loss: `BCE(control_success) + 0.1 × masked CE(pitch_type)`.
- 학습: AdamW, lr 0.002, batch 4096, 고정 3 epoch.
- 시드: 3, 4, 5, 6, 8, 13의 평균.
- 제출 결합: v11의 base+cell raw 확률 90% + masked-pitch NN 10%를 먼저 결합하고,
  그 뒤 기존 slope/shift, recent-middle, exact-PB route를 2024 source 잔차에 일관되게 refit.

고정 3 epoch는 비교 중 발견한 refit 선택 편향을 없애기 위한 것이다. 기존 NN 코드는
검증 최적 epoch에 따라 refit 길이가 달라졌고 refit 때 auxiliary loss도 빠져 있었다. 양쪽을
같은 epoch로 고정하고 refit에도 동일 보조 손실을 적용한 뒤 아래 결과를 다시 측정했다.

## 직접 구종 MoE가 탈락한 이유

seed42의 2023→2024 고정 비교에서:

- 제구 단독 MLP: 714.34
- masked 구종 auxiliary head: 753.25 (`+38.91`)
- 구종 조건부 MoE 주변화: 730.93 (`+16.59`, auxiliary보다 약함)

실제 구종 oracle은 강하지만 현재 행으로 맞힌 구종 분포는 정확도 약 53.6%라 제구 잔차를
안정적으로 routing하기엔 약하다. 반면 보조 분류 손실은 trunk가 투구 성향을 구분하도록
돕되, 잘못 맞힌 구종을 최종 제구 확률에 직접 강제하지 않는다.

## LB 판정과 정정

v13은 `1099.4652219091`로 v11보다 `−2.336845`였다. 후속 감사에서 위 rolling 실험은
전처리 artifact/QT를 한 시즌 더 과거에 동결했지만 v13은 전처리까지 2024에 full-fit해
검증 구조가 달라졌음을 확인했다. 제출형 full-fit을 과거에 재현하면 구종 보조 증분은
2022→23 `−198.662`(t=−3.758), 2023→24 `−123.688`(t=−6.348)로 반전했다.

따라서 **v13 full-fit 경로는 CLOSED**다. 원래 통과한 lagged-artifact 구조를 정확히
2025로 평행 이동한 `v14_pitch_mtl_lag`도 LB `1099.2989837237`로 v11 대비
`−2.5030834828`, v13 대비 `−0.1662381854` 하락했다. 두 경로 모두 패키지와 행 독립
감사를 통과했으므로 rolling 증분이 2024→25에 전이되지 않은 것이다. masked-pitch
auxiliary 전체 축을 CLOSED하며 추가 가중치·gate·refit 변형은 금지한다. 상세 원인·분해는
[`PITCH_MTL_LB_FAILURE_20260811.md`](PITCH_MTL_LB_FAILURE_20260811.md)에 기록했다.
